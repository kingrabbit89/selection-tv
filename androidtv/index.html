Installer la dernière version

L'APK expérimentale peut être installée à côté de l'application Jellyfin officielle. Le bouton ci-dessous pointe toujours vers la dernière compilation publiée.

Télécharger l’APK

Sur Android TV : télécharge l’APK, autorise temporairement l’installation d’applications inconnues pour le navigateur ou le gestionnaire de téléchargement utilisé, puis lance l’installation.

Nom de l’application : Jellyfin Sélection TV. Elle reste distincte de Jellyfin officiel.
